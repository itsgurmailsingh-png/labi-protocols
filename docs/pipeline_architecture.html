LAYER 3

Version Grouping + Quality Ranking

Waiting merge_and_dedup.py

MinHash LSH (128 perms) groups similar protocols as versions instead of deleting them. Only near-identical content (≥0.95 Jaccard) is treated as a true duplicate. Protocols between 0.70–0.95 similarity become version families.

JACCARD THRESHOLDS
≥ 0.95 → true duplicate → drop one
0.70–0.95 → same family → version group
< 0.70 → different protocol → keep both
QUALITY SCORE (determines parent)
quality = (runs × 3)
+ (peer_reviewed × 50)
+ bookmarks
+ (views / 100)
+ (steps × 0.5)
Example: "TRIzol RNA Extraction" version group
PARENT Rio DC, Ares M Jr — protocols.io score: 147 ✅ peer reviewed
v2 Chomczynski P — protocols.io score: 84 doi: 10.17504/xyz
v3 Nature Protocols — PubMed Central score: 61 doi: 10.1038/nprot.xxx
parent_protocol_id version_count quality_score doi author source_url peer_reviewed stats{ views, runs, bookmarks, forks }
